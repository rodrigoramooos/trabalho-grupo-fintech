## 📌 Sobre o Projeto

O **NEAR Protocol GPT** é um sistema de inteligência artificial especializado na análise do NEAR Protocol — uma plataforma blockchain de alta escalabilidade com relevância crescente no ecossistema FinTech.

O projeto é composto por **dois agentes principais** e **oito skills modulares**, desenvolvidos ao longo de duas entregas, cobrindo dimensões técnicas, económicas, regulatórias e estratégicas do protocolo.

> *"Em que medida o NEAR Protocol representa uma solução tecnicamente viável e economicamente sustentável para os desafios de escalabilidade, interoperabilidade e adoção das plataformas blockchain no contexto FinTech?"*
